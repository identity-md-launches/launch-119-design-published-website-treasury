# AssetFold design and forward model

This repository contains Parts A and B of a proposed treasury protocol for Robinhood Chain.

- `report.md` — protocol design, evidence, uncertainties, comparison, and verdict
- `model.py` — reproducible 12-month forward scenario model (Python standard library only)
- `data/scenarios.csv` — 60 monthly observations generated by the model
- `sources.md` — attributable public off-chain sources and source limitations

Run `python3 model.py` from this directory. This is a scenario model, not a backtest or forecast. It uses no blockchain/RPC data, and all numerical economic inputs are marked as assumptions.
